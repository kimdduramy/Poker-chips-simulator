# 앞으로 할 일

대화로 정해 둔 계획이에요. 하자고 할 때 여기서 골라 시작해요.

## 1. 게임 종류 늘리기

지금은 홀덤 하나예요. 테이블을 만들 때 게임 종류를 고르고, 종류마다 규칙 엔진만 바꿔 끼우는 구조로 늘려요.
방, 동기화, 방장, 기록, 되돌리기, 테스트 판은 그대로 같이 써요.

### 7포커 (세븐 포커)

한국 홈게임 기준 규칙이에요.

- **인원**: 2~7명. 7장 중 가장 좋은 5장으로 겨뤄요. 히든 3장, 오픈 4장이에요.
- **흐름**: 앤티 → 초이스(4장 받아 1장 버리고 1장 오픈) → 4구 → 5구 → 6구 → 7구(히든)
  → 쇼다운. 4구부터 7구까지 매번 베팅해요.
- **베팅 순서**: 매 라운드 오픈 카드 족보가 가장 높은 사람(보스)부터 시작해요.
  같으면 높은 숫자 → 무늬(♠ > ◆ > ♥ > ♣) 순서로 정해요.
- **베팅 용어**:
  - 삥: 최소 금액
  - 체크, 콜, 다이(폴드)
  - 따당: 앞 베팅의 2배
  - 쿼터, 하프, 풀: 콜한 뒤 팟의 1/4, 1/2, 전부를 더해요
- **족보**: 로티플 > 백스티플 > 스티플 > 포카드 > 풀하우스 > 플러시 > 마운틴 > 백스트레이트
  > 스트레이트 > 트리플 > 투페어 > 원페어 > 탑
- **동점**: 무늬로 가려서 보통 팟을 나누지 않아요.
- **앱 카드 모드에서 좋은 점**: 앱이 오픈 카드를 알아서 보스를 자동으로 정할 수 있어요.
  실물 카드 모드에서는 방장이 보스를 골라 줘요.
- **시작 전에 정할 하우스 룰**:
  - 처음 4장 받고 1장 버리기, 아니면 3장으로 바로 시작
  - 3구부터 베팅, 아니면 4구부터
  - 하프까지만, 아니면 풀까지 허용
  - 라운드당 레이즈 횟수
  - 체크 허용, 아니면 삥부터 시작

### 화투 (고스톱)

- 할 때 규칙(점수, 고/스톱, 피박·광박, 흔들기 등)과 인원(2~3명, 광 팔기)을 먼저 정해요.

### 마작 (다음 차례)

**정해진 것**

- 정식 리치 마작(일본식), 4인 기준이에요.
- 실물 마작패가 없어서 **앱이 패를 나눠주는 완전한 마작**으로 만들어요.
- 규칙 엔진은 GitHub의 kobalab 電脳麻将을 바탕으로 해요. 전부 MIT라서 우리 저장소에 써도 돼요.
  - `kobalab/majiang-core`: 패산, 손패, 울기, 화료 판정, 역·판·부·점수 계산을 맡아요. 우리 서버(Durable Object)에서 돌려요.
  - `kobalab/majiang-ai`: 테스트 판 봇이에요. 인원이 모자랄 때 채워 줘요.
  - `kobalab/majiang-ui`: 패 그림을 참고하거나 가져다 써요. 그림 라이선스는 먼저 확인해요.
  - `kobalab/majiang-server`, `kobalab/Majiang`: 구조와 화면 흐름만 참고해요.
  - JS라서 우리 쪽에서 타입을 붙이고, 동작은 우리 테스트로 검증해요.
  - 코드와 설명이 일본어이고, 이름이 중국어 병음이에요(손패 `shoupai`, 화료 `hule`).
- 친구들이 마작 초보라서 **초보 도우미**를 강하게 넣어요.
  - 론/쯔모 버튼은 실제로 이길 수 있을 때만 떠요. 역이 없거나 후리텐이면 안 떠요.
  - 리치할 수 있으면 버튼을 띄우고, 무엇을 버리면 리치되는지 표시해요.
  - 치·퐁·깡 버튼도 할 수 있을 때만 떠요.
  - 이기면 역 이름, 판·부, 점수를 자동으로 계산해서 보여줘요.
  - 용어 설명과 역 표를 게임 중에 바로 볼 수 있게 해요. 홀덤의 족보·용어 창과 같은 방식이에요.
  - 도움말에 "몸통 4개 + 머리 1개, 역은 리치·탕야오·역패부터" 같은 초보용 설명을 넣어요.

**단계** (PR마다 하나씩, 매번 스크린샷으로 확인)

1. majiang-core를 서버에 붙여요: 배패, 쯔모·버림, 화료, 유국. 남의 패를 숨기는 건 홀덤 카드 모드 구조를 다시 써요.
2. 울기: 치·퐁·깡. 누가 버리면 다른 사람 응답을 기다리고, 우선순위는 론 > 퐁·깡 > 치예요.
3. 리치·점수: 도라·뒷도라, 점수 주고받기, 친 넘기기, 본장·공탁.
4. 폰 화면: 내 손패, 네 사람의 버림패와 운 패, 남은 패 수, 도라, 울기·리치·화료 버튼, 마작패 그림.
5. 마작 테마: 테이블을 만들 때 게임 종류(홀덤/마작)를 고르면 배경도 매트 초록 같은 테마로 바뀌어요(아래 2번).
6. 봇: majiang-ai로 테스트 판에서 혼자 연습해요.

**그대로 쓸 것**: 방, 실시간 동기화, 방장, 큰 화면, 기록(기보), 되돌리기, 테스트 판, 공정성 테스트 구조.

**시작할 때 정할 것**: 시작 점수(보통 25,000), 반장전/동풍전, 적도라 유무, 쿠이탕(울고 탕야오) 허용,
3인 마작도 할지, 차례 시간 제한.

**참고만 할 것** (GPL/AGPL이라 코드는 가져오지 않아요): BH4HPA/riichi-scoreboard, 1Computer1/riichi-tracker.

## 2. 게임 종류마다 배경 테마

- 고른 게임 종류를 `<html data-game="holdem | sevenpoker | gostop | mahjong">`에 걸어요.
  종류마다 색 변수(`--bg`, `--surface`, `--accent` 등) 세트를 정의해요. 카드 뒷면 고르기와 같은 방식이에요.
- 예시:
  - 홀덤: 지금처럼 흰 바탕과 노랑
  - 고스톱: 담요 초록이나 화투 빨강
  - 마작: 매트 초록과 상아색
- 다크 모드 색도 종류마다 따로 맞춰요.

## 3. 카드 모드에서 핸드를 넘나드는 되돌리기

지금은 카드 모드에서 이전 핸드로 되돌릴 수 없어요. 카드를 지금 핸드 것만 들고 있고,
되돌린 뒤 다시 시작하면 새로 섞여서 패를 다시 뽑을 수 있게 되기 때문이에요.

- 핸드별 카드를 핸드 번호와 함께 보관해요. 이전 핸드로 되돌리면 그때 카드를 복원해요.
- 되돌린 뒤 "다음 핸드 시작"을 다시 눌러도 새로 섞지 않고 처음 나눠준 카드를 그대로 써요.

## 4. 카드 모드에서 남은 것

- **머크**: 쇼다운에서 진 사람이 카드를 안 보여주고 버릴 수 있게 해요.
- **방장 비상 승자 지정**: 판정이 이상할 때 방장이 승자를 고칠 수 있게 해요.
- **올인 런아웃 연출**: 남은 카드를 한 장씩 천천히 까요.
- **폰 없는 자리, 테스트 봇의 카드**: 지금은 아무도 볼 수 없어요.

## 5. 브랜치용 테스트 서버

브랜치 미리보기 화면도 지금은 실제 서버에 붙어요. Durable Object를 쓰는 워커는
Cloudflare가 브랜치별 미리보기를 만들어 주지 않아서예요.

- `worker/wrangler.jsonc`에 `staging` 환경(`chip-poker-api-staging`)을 추가해요.
- `wrangler.toml`의 Pages 미리보기 환경이 테스트 서버로 연결되게 해요.
- Cloudflare 대시보드에서 직접 해야 할 것: Workers Builds에서 main이 아닌 브랜치를 `wrangler deploy --env staging`으로 배포하게 설정해요.
